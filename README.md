# web_Marketing.pe

Proyecto Nuxt 3 con Tailwind, Pinia, Swiper y Toastification.

### Secciones agregadas

Se añadieron secciones inspiradas en una página de agencia:

- `sections/HeroSection.vue`
- `sections/ClientsSection.vue`
- `sections/AboutSection.vue`
- `sections/ServicesSection.vue`
- `sections/StatsSection.vue`
- `sections/PortfolioSection.vue`
- `sections/TestimonialsSection.vue`
- `sections/CTASection.vue`
- `sections/ContactSection.vue`

Componentes reutilizables en `components/ui`:

- `SectionContainer.vue` — contenedor con padding configurable
- `SectionHeading.vue` — encabezado con eyebrow y subtítulo
- `AppButton.vue` — botón con variantes
- `Badge.vue` — insignia para acentos

Puedes editar el orden en `pages/index.vue`.
